Gaming Hub

Yang bisa dilakukan HBG

HBG (Helper Boost Game) adalah menu utama aplikasi. Semua perubahan bisa dibatalkan dengan satu tombol.

Booster FPS
Menutup proses latar dan meminta Game Mode performa untuk game yang kamu isi package-nya. Game Mode butuh Android 12 atau lebih baru, dan game harus mendukungnya.
Anti-aliasing
Menyalakan Force 4x MSAA. Hanya berpengaruh pada game OpenGL ES 2.0 dan perlu restart game.
Resolusi
Menurunkan resolusi layar ke 85%, 70%, atau 50% agar GPU lebih ringan. Density ikut disesuaikan supaya tampilan tetap proporsional.
Paksa CPU
Mengaktifkan mode performa tetap. Perangkat bisa menjadi panas, dan tidak semua HP mendukungnya.
Pantau suhu
Suhu baterai tampil langsung di layar HBG, dengan peringatan merah saat mencapai 42°C.
Reset semua
Mengembalikan resolusi, density, MSAA, dan mode performa ke kondisi awal.
Recorder dan Chat
Masih dikunci dan sedang dikembangkan.

Cara memasang

  1. Unduh Gaming_Hub-V1.apk dari tombol di atas, lalu baca keterangan file-nya di bagian berikutnya.
  2. Buka file APK dan izinkan pemasangan dari sumber ini saat HP memintanya.
  3. Pasang dan jalankan aplikasi Shizuku (lewat debugging nirkabel atau root).
  4. Buka Gaming Hub, masuk ke tab HBG, dan baca peringatan risikonya.
  5. Tekan Minta izin Shizuku. Setelah status berubah hijau, pilih opsi dan tekan Terapkan.

Peringatan dan batasan

Memaksa performa dapat membuat perangkat panas. Jika tetap memakainya, semua risiko ditanggung pengguna.

Roblox. Sebagian pengaturan, seperti Game Mode dan anti-aliasing, bisa diabaikan atau direset oleh game maupun sistem. Dari pengujian, pembersihan proses latar dan perubahan resolusi tetap berfungsi. Roblox versi lama memang bisa dicoba, tetapi kemungkinan tidak bisa dimainkan karena wajib update, dan APK dari sumber tidak resmi bisa berbahaya.

Hasil berbeda di tiap HP dan versi Android. Kami sedang mencari cara agar pengaturan performa bisa tersimpan dengan baik.

Pertanyaan umum

Kenapa Google Drive atau Play Protect memberi peringatan?

Google Drive tidak bisa memindai file APK, jadi akan muncul peringatan standar. Versi V1 juga masih berupa build debug yang belum diterbitkan di Play Store. Karena itu, pindai dulu di VirusTotal jika kamu ragu.

Izin apa yang diminta aplikasi?

Akses internet, yang disiapkan untuk fitur chat nanti. Perintah sistem hanya berjalan lewat izin Shizuku yang kamu berikan sendiri di dialog Shizuku.

Layar jadi aneh setelah Terapkan. Bagaimana mengembalikannya?

Tekan Reset semua di tab HBG. Cadangan lewat ADB: adb shell wm size reset lalu adb shell wm density reset.

Apakah butuh root?

Tidak. Shizuku bisa dijalankan lewat debugging nirkabel.
